🚗 PingCar

Die sichere Lösung, um Fahrzeughalter zu kontaktieren – ohne Telefonnummer und ohne persönliche Daten. Scannen Sie einfach den QR-Code und senden Sie eine Benachrichtigung.

Bald verfügbar

So funktioniert PingCar

1. Konto erstellen

Registrieren Sie sich kostenlos bei PingCar.

2. Persönlichen QR-Code erhalten

Jeder Benutzer erhält einen einzigartigen QR-Code.

3. QR-Code am Fahrzeug anbringen

Bringen Sie den QR-Code gut sichtbar an Ihrem Fahrzeug an.

4. QR-Code scannen

Andere Personen können den Code scannen, ohne Ihre Telefonnummer oder persönlichen Daten zu sehen.

5. Nachricht erhalten

Sie erhalten sofort eine Benachrichtigung in der PingCar-App.

Nach dem Scannen

🚗 Mein Fahrzeug wird blockiert
Informieren Sie den Fahrzeughalter schnell und einfach.
💡 Das Licht ist eingeschaltet
Benachrichtigen Sie den Fahrer, bevor die Batterie leer wird.
🚨 Das Fahrzeug wurde beschädigt
Senden Sie sofort eine Benachrichtigung.
🔑 Etwas vergessen
Der Fahrer kann schnell informiert werden.
✉️ Andere Mitteilung
Senden Sie eine kurze Nachricht über PingCar.
