So funktioniert PingCar

1. Registrieren

Erstellen Sie kostenlos Ihr PingCar-Konto.

2. QR-Code erhalten

Sie erhalten einen persönlichen QR-Code für Ihr Fahrzeug.

3. QR-Code anbringen

Befestigen Sie den QR-Code gut sichtbar an Ihrem Fahrzeug.

4. QR-Code scannen

Eine andere Person scannt den QR-Code mit dem Smartphone.

5. Benachrichtigung

Sie erhalten sofort eine Nachricht in der PingCar-App.
